# גשר של דורות

אפליקציה סטטית לחיזוק הקשר בין סבים, סבתות ונכדים. היא כוללת מנוע פעילויות, קלפי שיחה, פרויקטים משפחתיים ומדריך נגיש.

## העלאה ל-GitHub Pages

1. מעלים את כל הקבצים שבתיקייה לשורש המאגר.
2. ב-GitHub נכנסים אל **Settings → Pages**.
3. תחת **Build and deployment** בוחרים **Deploy from a branch**.
4. בוחרים בענף `main` ובתיקייה `/ (root)` ושומרים.

האפליקציה אינה דורשת שרת, מסד נתונים או מפתחות API. אין בה חשבונות משתמשים והיא אינה שומרת מידע.
